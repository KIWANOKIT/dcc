# Building the AI Caller APK

- Gradle project root: this `android/` folder (contains `settings.gradle.kts`, `gradlew`).
- Application module: `app`  (set the "Module" field to `app` if your build service asks).
- Build command: `./gradlew assembleDebug`
- Output: `app/build/outputs/apk/debug/app-debug.apk`
- Needs JDK 17 and Android SDK platform 34.
